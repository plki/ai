# 需求文档 - 云端平台 v2（前后端分离架构）

Feature Name: cloud-platform-v2
Version: 1.0
Date: 2026-09-06

## 1 简介与目标

将现有 AI 云聊（Cloudflare Pages 单文件）重构为前后端分离的完整平台。

**前端**（Vite + Vue 3）：用户聊天界面 + 管理后台  
**后端**（Cloudflare Workers / Pages Functions）：API 中转 + 模型管理 + 文件上传 + 联网搜索 + 运营管理  
**存储**：Cloudflare KV（配置/会话）+ D1（结构化数据）+ R2（文件）

## 2 术语表

| 术语 | 定义 |
|------|------|
| 用户 | 普通访客，可发起对话、上传文件、开启联网搜索 |
| 管理员 | 拥有后台访问权限，可管理 API Key、模型、搜索服务、配额 |
| 中转 Key | 管理员在后台配置的 OpenAI 兼容 API Key，供用户免费调用 |
| 子 Key | 用户在前端申请的个人调用凭证，绑定配额限制 |
| 联网搜索 | 将用户问题转换为搜索请求，取前 N 条结果作为上下文注入 prompt |
| 搜索 API | 第三方搜索服务（SerpAPI / Bing Search / Tavily），管理员在后台配置 |
| R2 对象存储 | Cloudflare R2，存储用户上传的附件文件 |
| KV 存储 | Cloudflare KV，存储配置、Token 哈希、会话摘要 |
| D1 数据库 | Cloudflare D1 SQLite，存储结构化日志、配额记录、用户子 Key |

## 3 用户角色与权限

### 3.1 普通用户

| 功能 | 描述 |
|------|------|
| 对话聊天 | 基于 OpenAI 兼容 API 的 SSE 流式对话 |
| 多会话管理 | localStorage 存会话历史，可切换、删除、重命名 |
| 文件上传 | 上传图片/文档作为上下文附件，存 R2，URL 传给 AI |
| 联网搜索 | 开启后自动将搜索结果注入上下文 |
| 申请子 Key | 申请个人 API Key 供外部工具调用（curl / API） |
| 查看配额 | 查看子 Key 的调用额度余量 |

### 3.2 管理员

| 功能 | 描述 |
|------|------|
| 后台登录 | 首次访问设置 bcrypt 哈希密码，后续登录验证 |
| 上游 API 配置 | 配置 Base URL、API Key、默认模型 |
| 子 Key 管理 | 查看/编辑/禁用所有用户的子 Key |
| 搜索服务配置 | 配置 SerpAPI / Bing / Tavily 的 API Key |
| 调用日志 | 查看完整调用记录（用户 / 模型 / token / 时间） |
| 运营统计 | 实时调用量、配额使用率、热力图 |

## 4 功能需求

### FR-001：聊天对话

**用户故事**：作为访客，我希望通过浏览器与 AI 对话，以便随时获得智能助手的帮助。

- 接收文本输入，支持 Shift+Enter 换行，Enter 发送
- SSE 流式输出，Markdown 实时渲染，代码高亮
- 显示"正在思考"状态，支持中断生成
- 多会话切换，会话标题自动截取首条用户消息
- 对话历史存 localStorage（用户侧）

### FR-002：文件上传

**用户故事**：作为用户，我希望上传图片或文档，让 AI 基于这些内容回答问题。

- 支持拖拽上传 + 点击选择，文件类型限制：图片（png/jpg/gif/webp/svg）、文档（pdf/txt/md/docx）
- 单文件最大 25MB，存 Cloudflare R2，返回公开访问 URL
- 上传时显示进度条，上传完成后显示预览缩略图（图片）或文件名+大小（文档）
- 文件 URL 作为 `image_url`（多模态模型）或 text content 注入 messages
- 上传文件列表可在当前会话中管理（删除）

### FR-003：联网搜索

**用户故事**：作为用户，我希望 AI 能联网获取最新信息，而不仅依赖训练数据。

- 用户可在输入框旁开启"联网"开关
- 开启时，每次发送消息前先调用搜索 API（Tavily / SerpAPI / Bing），取前 5 条结果
- 搜索结果格式：`[搜索关键词] 来源标题 - 摘要\n来源：URL`
- 将搜索结果拼接到 user message 之前作为 system prompt 补充
- 搜索计入门户配额的 API 调用（算 1 次）

### FR-004：子 Key 与配额管理

**用户故事**：作为用户，我需要个人 API Key 供其他工具调用，同时希望看到配额余量。

- 用户可申请子 Key（前端一键生成），Key 格式：`sk-user-{uuid}`
- 子 Key 绑定调用次数上限（默认 100 次/天）、Token 上限（默认 100k/天）
- 用户可在个人面板查看配额余量（剩余次数 / 剩余 Token）
- 配额用尽时返回 429，禁止调用

### FR-005：后台登录与安全

**用户故事**：作为管理员，我需要安全登录后台，保护平台配置不被未授权用户访问。

- 首次访问 `/admin` 时进入初始化流程：设置管理员密码
- 密码 bcrypt 哈希后存入 Cloudflare KV（key: `admin:hash`）
- 后续登录时验证哈希，登录成功后写入 session cookie（HttpOnly，7天有效）
- 登录页面防暴力：同一 IP 连续 5 次失败锁定 15 分钟
- 登出清除 session

### FR-006：上游 API 管理

**用户故事**：作为管理员，我需要配置上游 API 使平台正常运行。

- 配置项：Base URL、API Key、模型列表、默认模型、并发上限
- 支持多组配置（主备切换）
- API Key 在后台隐藏显示，点击可复制（脱敏：前 6 位 + *** + 后 4 位）

### FR-007：调用日志

**用户故事**：作为管理员，我需要查看所有 API 调用记录以便监控和排查问题。

- 记录字段：时间、调用方 IP、模型、消息长度、Token 消耗、响应时间、错误信息
- 日志存 D1，支持分页查询（每页 50 条）
- 支持按子 Key / 模型名 / 日期范围筛选
- 日志保留 30 天，自动清理

### FR-008：运营统计面板

**用户故事**：作为管理员，我希望看到实时运营数据，了解平台使用状况。

- 今日调用量 / 本月调用量
- 各模型调用占比（饼图）
- 24 小时调用趋势（折线图）
- 配额使用率排行（Top 10 子 Key）
- 实时活跃连接数

## 5 非功能需求

### NFR-001：性能

- API 中转响应时间 < 200ms（不含上游 AI 延迟）
- 文件上传到 R2 可访问 URL 生成 < 3s（不含文件大小因素）
- 搜索 API 超时 8s，自动降级返回"搜索暂不可用"

### NFR-002：安全

- 所有用户上传文件经 MIME type 验证，拒绝危险类型（exe / sh / bat 等）
- R2 文件 URL 设置 Cache-Control 防止永久缓存敏感内容
- 管理员 session 仅限 7 天有效期
- API Key 存储不记录到日志
- 路径穿越防护：所有文件操作使用 `resolve()` 规范化路径

### NFR-003：可用性

- 搜索 API 不可用时降级处理，不阻断对话
- 上游 API 错误（429 / 500）原样返回给用户，显示友好错误
- KV / D1 / R2 任一服务异常时返回 503，不崩溃

### NFR-004：部署

- 前端构建产物部署到 Cloudflare Pages
- 后端 Workers 部署到 Cloudflare Workers
- 环境变量通过 Cloudflare Dashboard 配置，不写代码
- GitHub Actions 触发部署（推送 main 分支）

## 7 验收标准

1. 用户无需登录即可发起对话（匿名使用）
2. 用户上传 5MB PDF 文件后，AI 能正确读取并回答相关问题
3. 开启联网搜索后，AI 能引用搜索结果中的最新信息
4. 管理员成功设置密码后，后续访问 `/admin/*` 无需重新设置
5. 用户申请子 Key 后，使用该 Key 能成功调用 API（curl 测试）
6. 配额用尽时 API 返回 429 错误
7. 调用日志准确记录每次 API 请求的模型和 token 消耗
8. 部署到 Cloudflare Pages + Workers 后，全球可访问

## 8 排除范围

- 微信/钉钉等第三方平台集成
- 移动端原生 App
- 多租户（多站点隔离）
- 计费和结算系统
- 模型微调或训练
