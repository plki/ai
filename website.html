先思考，再确认，后执行

默认开启「执行前确认」。当 AI 决定调用工具时，会先展示完整的执行计划，等待你的批准——你始终掌握控制权。

  • 输入 y 执行，输入 n 取消
  • 网页版弹出「允许执行 / 拒绝」按钮
  • 确认模式可用 config confirm off 关闭

任意 OpenAI 兼容云端 API

不想装 Ollama？配置你自己的云端 API 即可，支持任意 OpenAI 兼容接口（可自定义 Base URL、端口、API Key、模型名）。

  • DeepSeek / 通义 / Moonshot / OpenAI / 本地 vLLM
  • 网页版左下角「设置」直接填入
  • 云端模式同样支持 function calling 工具调用
配置云端 API
$ config provider cloud
$ config api https://api.deepseek.com/v1 sk-*** deepseek-chat
✓ provider: cloud
✓ model: deepseek-chat

快速开始

三分钟上手，Windows 用户更有一键安装脚本。

安装依赖

安装 Python 依赖。Windows 用户可直接双击 install.bat 一键完成安装 + Ollama 引导。

pip install -r requirements.txt

命令行启动

进入 AI 对话界面。Windows 用户可双击 launcher.bat，自动管理 Ollama 生命周期。

python main.py

网页版启动

浏览器访问 http://localhost:7860，获得图形化聊天界面。

python main.py web

☁️ 云端在线版

免费部署到 Cloudflare Pages，生成一个公网链接，别人打开网页即可用，无需下载安装任何东西。

登录 Cloudflare

打开 dash.cloudflare.com 并登录（免费注册），进入 Workers 与 Pages → 创建 → Pages → 连接到 Git。

选择本仓库

框架预设选 None，构建命令与输出目录留空。关键一步：把根目录改为 cloudflare，否则 functions/ 不会生效。

保存并部署

约 1 分钟后得到公网地址 https://你的项目名.pages.dev，别人打开即可对话。

https://<项目名>.pages.dev
