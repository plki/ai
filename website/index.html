部署步骤
1登录 dash.cloudflare.com → Workers 与 Pages → 创建 → Pages → 连接到 Git
2框架预设选 None，构建命令与输出目录留空
3将根目录改为 cloudflare，保存并部署
4约 1 分钟后得到 https://<项目名>.pages.dev

❓ 常见问题

有疑问？看这里

需要联网才能使用吗？
本地模式下完全离线，使用 Ollama 在本机运行模型，数据不会发送到任何服务器。切换到云端 API 时才需要联网。
支持哪些操作系统？
支持 Windows、macOS、Linux。只要装有 Python 3.9+ 即可运行。Windows 用户还有一键安装脚本（install.bat）。
支持哪些 AI 模型？
本地：任何 Ollama 支持的模型（Llama、Qwen、Mistral 等）。云端：任何 OpenAI 兼容 API（DeepSeek、通义千问、Moonshot、OpenAI 等）。支持自定义 Base URL。
如何更新到最新版本？
进入项目目录，执行 git pull 拉取最新代码，然后 pip install -r requirements.txt 更新依赖即可。
API Key 安全吗？
本地模式下 API Key 只存储在 config/config.json。云端网页版中，API Key 只保存在访问者的浏览器本地存储，不会经过中间服务器。
可以贡献代码吗？
欢迎！本项目采用 MIT 许可证。你可以提交 Issue 反馈问题，或提交 Pull Request 贡献代码。我们非常感谢社区的参与。
